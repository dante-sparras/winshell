# Winshell has its own Windows-first API, not Quickshell's

Winshell no longer loads Quickshell configurations. Its modules are `Winshell` and `Winshell.*`, and its types are named for what they are on Windows: `Audio` rather than `Pipewire`, `MediaSession` rather than `MprisPlayer`, `AppWindow` rather than `Toplevel`. Matching Quickshell v0.3.2 (ADR-0004) kept Linux names on every Windows service and kept modules that load and do nothing, such as `Greetd` and `I3`, and a configuration still had to be rewritten for its Windows paths, apps and services. There is no `Quickshell.*` alias layer: two names for every type would keep the Linux ones alive in docs and examples. [Migrating from Quickshell](../migrating-from-quickshell.md) maps the old names to the new ones. The Qt Quick modules stay, because they are the QML language's own library, not Quickshell's.
